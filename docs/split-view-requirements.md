# Side Panel 分屏功能需求

## 目标

为 SidePanel Navigator 增加分屏浏览能力，让用户可以在同一个 Chrome Side Panel 内同时查看多个不同网站。功能应保持轻量、可扫视、适合窄侧栏空间，并复用现有快捷站点、右键打开和已打开页面管理能力。

## 支持的布局

分屏模式提供四种布局：

- 单屏：默认模式，只显示一个网站。
- 左右分屏：显示两个并排 pane，适合对照网页和文档。
- 上下分屏：显示两个纵向堆叠 pane，适合窄侧栏中保留上下文。
- 四宫格：显示四个 pane，适合同时监控多个轻量页面。

每个 pane 是一个独立浏览区域。pane 内可以为空，也可以显示一个网站 iframe。

## 核心交互

### 布局切换

- 顶部工具栏提供布局切换按钮。
- 当前布局按钮应有选中态。
- 从单屏切到双屏或四宫格时，当前网站保留在第一个 pane 中，新 pane 为空。
- 从多 pane 切回单屏时，优先保留当前激活 pane 的网站；如果当前激活 pane 为空，则保留第一个非空 pane。
- 切换布局不会删除已打开页面列表中的记录。

### 激活 pane

- 点击任意 pane 会将其设为当前激活 pane。
- 激活 pane 需要有明确但克制的视觉标识。
- 快捷站点、已打开页面、右键打开页面都默认加载到当前激活 pane。

### 打开网站

- 点击顶部快捷站点：将网站加载到当前激活 pane。
- 右键“在侧栏打开”：将目标作为临时页面加载到当前激活 pane。
- 点击“已打开页面”中的页面：将该页面加载到当前激活 pane。
- 如果当前激活 pane 不在当前布局中，则自动回落到当前布局的第一个 pane。

### 关闭和清空

- pane 右上角提供清空按钮，只清空当前 pane，不删除已打开页面记录。
- “已打开页面”的关闭按钮会删除该页面记录，并从所有 pane 中移除该 URL。
- 如果删除的是单屏当前页面，单屏可以自动回落到最近使用的其他页面；多 pane 模式下对应 pane 保持为空，避免意外替换用户正在对照的内容。

## 视觉与可用性要求

- 顶部工具栏保持 40px 高度，不增加额外导航层。
- 分屏按钮使用图形化布局图标，并提供 `title` 和 `aria-label`。
- pane 标题栏尽量紧凑，只显示当前网站标题或空 pane 状态。
- 空 pane 应提示用户可点击快捷站点打开内容。
- 在窄屏宽度下，左右分屏自动改为上下堆叠，避免 iframe 被压缩到不可用。
- 已打开页面浮层出现时，不应遮挡 pane 标题和操作区。

## 非目标

- 不提供可拖拽调整 pane 尺寸。
- 不持久化当前分屏布局和 pane 内容到下一次浏览器会话。
- 不突破目标网站自身登录、CSP、反嵌套或 iframe 限制。
- 不支持同一个 iframe 实例在多个 pane 中复用；同一 URL 可重新加载到当前 pane。

## 验收标准

- 可以在单屏、左右分屏、上下分屏、四宫格之间切换。
- 在任意布局中点击 pane 后，再点击快捷站点，网站会进入被点击的 pane。
- 已打开页面列表中的页面可以被重新分配到当前激活 pane。
- 关闭已打开页面会从所有 pane 移除对应 URL。
- `pnpm verify` 通过。
- 本地开发页面在桌面和窄宽度视口下无明显重叠、空白或控件不可点击问题。
