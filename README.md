# SidePanel

把常用网站放进 Chrome 侧栏，边浏览主页面边使用 AI、文档、工具站和工作台。

SidePanel 适合想减少标签页切换的人：你可以把 ChatGPT、豆包、Kimi、文档、代码仓库、监控页或任意常用网页固定在浏览器右侧，需要时一键打开，临时页面也可以随手放进侧栏。

## 它能帮你做什么

- 在不离开当前网页的情况下打开 AI 助手、资料页或工具站。
- 把常用网站收进一个窄侧栏，减少多个浏览器标签来回切换。
- 临时把当前页面或链接放进侧栏，用完后像关闭标签一样移除。
- 将重要网站加入快捷入口，下次点击图标即可打开。
- 同时查看多个网页，例如一边看资料一边问 AI，或同时监控多个页面。

## 主要功能

### 快速打开侧栏

- 点击 Chrome 工具栏里的 SidePanel 图标即可打开侧栏。
- 在任意页面右键，选择「在侧栏打开」，当前页面会作为临时页面进入侧栏。
- 在任意链接上右键，选择「在侧栏打开」，链接会直接在侧栏里打开。
- 使用快捷键打开当前页面到侧栏。

默认快捷键：

| 操作 | Windows / Linux / ChromeOS | macOS |
| --- | --- | --- |
| 在侧栏打开当前页面 | `Alt+Shift+S` | `Control+Shift+S` |
| 将当前页面加入侧栏 | `Alt+Shift+A` | `Control+Shift+A` |

如果默认快捷键和你的浏览器或系统冲突，可以打开 `chrome://extensions/shortcuts` 自定义。

### 管理你的快捷网站

- 内置 ChatGPT、豆包、Kimi 等常用入口。
- 可以新增、编辑、删除自己的快捷网站。
- 支持用 emoji、文字或图片链接作为站点图标。
- 快捷网站支持拖拽排序，常用的放在前面。
- 在页面或链接上右键选择「加入侧边栏」，可以直接保存为快捷入口。

### 多页面与分屏浏览

- 已打开页面会显示在侧栏的页面列表里，方便来回切换。
- 支持单屏、左右分屏、上下分屏和四宫格分屏。
- 点击某个分屏后，再点击快捷网站，该网站会进入当前选中的分屏。
- 临时页面可以关闭，快捷网站仍保留在你的导航列表里。

### 中英文界面

插件会根据浏览器语言自动显示中文或英文：

- `zh*` 浏览器语言显示中文。
- 其他语言默认显示英文。

## 安装使用

### 从源码安装

```bash
pnpm install
pnpm build
```

然后在 Chrome 中加载：

1. 打开 `chrome://extensions/`
2. 开启「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择项目生成的 `dist` 目录

### 基本使用流程

1. 点击浏览器工具栏里的 SidePanel 图标。
2. 在右侧快捷栏点击任意网站图标，即可在侧栏中打开。
3. 点击分屏按钮，切换单屏、左右分屏、上下分屏或四宫格。
4. 点击齿轮按钮，管理快捷网站。
5. 在网页或链接上右键，选择「在侧栏打开」或「加入侧边栏」。
6. 需要调整快捷键时，打开 `chrome://extensions/shortcuts` 修改。

## 使用限制

- 部分网站可能因为登录策略、安全策略或反嵌入限制，无法完整显示在侧栏里。
- 插件会在打开或添加具体站点时申请对应站点权限，用来提升侧栏内网页加载兼容性。
- 建议优先用于个人效率场景；如果用于团队环境，请先评估站点权限和安全边界。
